# OMS 亮点

OMS 是订单中枢：多渠道接单、审核、分仓、预占，再把出库推给仓储、把运单交给运输。

1. **一条状态机走完履约。** 已创建、已审核、已分配、已推仓、已出库、已完成，挂起和取消插在规则允许的节点上，不会把已支付的单洗成别的状态。
2. **分仓和拆单按规则自动做。** 按省份、渠道和路由规则选仓，支持多仓自动拆单和手工拆单，也支持一键处理。
3. **渠道库存和仓库库存分开算。** 可售量按比例、固定量或限定仓分配，预占、释放、扣减、退回都留流水。
4. **渠道、仓储、运输从开放接口进来。** 店铺下单、取消、可售查询，以及仓储发货、退货入库、运输签收和轨迹，都走 `/api/open`，按来源单号幂等。
5. **控制塔能直接改这张单。** 挂起、解挂、改仓、自动过审、取消、加急有统一指令口。挂起只接受已创建和已审核；加急改的是优先级，不改状态机。
